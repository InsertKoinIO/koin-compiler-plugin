[Koin][KOIN-W003] Graph not verifiable at compile time: entry point startKoin { … } loads a module set computed at runtime: compile safety cannot read an if/when expression.
  Compile-time dependency checks are skipped for this entry point; Koin's checkModules() still verifies it at runtime.
  Pass module vals, module functions or MyModule::class directly, or a listOf(...) / '+' of those, so compile safety can follow them.
